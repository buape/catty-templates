### THESE ARE TEMPLATES. YOU SHOULD NOT DIRECTLY COPY AND USE THEM. SEND THE LINK TO YOUR AGENT AND CUSTOMIZE THESE FOR YOURSELF

This repository contains templates that you can give to your agent for skills and jobs that work well for the Golden Path. See the Catty Golden Path document for more details.

## Notification jobs

- [GitHub notifications](jobs/github-notifications): assignments, mentions, review requests, and follow-up on the agent's own PRs.
- [Orbit notifications](jobs/orbit-notifications): mentions, assignments, due dates, and delivery failures through official MCP access.

Give your agent the relevant folder and ask it to customize the placeholders, authentication, reporting, and workspace policies before enabling it. Each folder contains normal `prompt.md`, `meta.toml`, and Python scripts plus setup notes; no template engine or credentials.
